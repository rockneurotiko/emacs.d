Lesson 0002 · ~10 minutes

Things — the C-SPC killer

Skill Structural selection · Mission Refactor without leaving normal state

Why this lesson, for you specifically

You said: "I build regions by hand with C-SPC and move." Ten years of muscle memory.

That habit is the single biggest thing standing between you and meow's payoff. Every time you press C-SPC and move, you're doing in 4–8 keystrokes what meow does in 2. Things are how you stop doing that — without losing the selection-first thinking you just learned in Lesson 0001.

The idea

A thing is a structural unit of text: a paragraph, a string, the contents of parens, a function, the whole buffer. Meow gives you four verbs to select relative to a thing, and a second key to say which thing.

KeyCommandWhat it selects
,meow-inner-of-thingthe inside of the thing (no delimiters)
.meow-bounds-of-thingthe whole thing (with delimiters)
<meow-beginning-of-thingfrom point to start of thing
>meow-end-of-thingfrom point to end of thing

Then a second key picks the thing:

KeyThing
rround parens ( )
ssquare brackets [ ]
ccurly braces { }
gstring " "
pparagraph
lline
ddefun (function)
bbuffer

So ,g = "inner of string" — selects the string contents without the quotes. .d = "whole defun." Two keystrokes.

"meow-inner-of-thing — Select the inner part of thing. e.g. A Lisp expression without parentheses."
— meow COMMANDS.org

Inner vs bounds — the only thing you must remember

, inner

"Give me what's inside."

("hello world")
   ^^^^^^^^^^^

Selection on a string: just the text, no quotes.

. bounds

"Give me the whole thing."

("hello world")
  ^^^^^^^^^^^^^

Selection on a string: quotes included.

Mnemonic: comma is small (inner), period is bigger (whole).

The Emacs translation table

Since you've been on standard Emacs for 10+ years, here's how each of these maps to something you may already know:

Old habitNew move
C-SPC then M-} (mark to end of paragraph).p — bounds of paragraph
C-SPC then C-M-e (end of defun).d — bounds of defun
M-h (mark-paragraph).p
C-M-h (mark-defun).d
C-x h (mark-whole-buffer).b
no easy equivalent,g — inside a string
no easy equivalent,r — inside parens

The last two rows are the cleanest wins — things you'd build by hand today that become one keystroke pair.

Drill

Setup

Open a scratch buffer. Paste:

defmodule Greeter do
  @doc "Greets a person by name and returns a friendly message."
  def hello(name) do
    parts = ["Hello", name, "welcome aboard"]
    Enum.join(parts, ", ")
  end

  def goodbye(name) do
    "See you later, #{name}!"
  end
end

Reps — feel the things

  1. Put cursor anywhere inside "Greets a person...". Press ,g.
    → Selection: just the text inside the quotes.
  2. g (cancel selection). Now .g.
    → Selection: the string including quotes. Feel the difference.
  3. Put cursor inside the [...] on the parts = line. Press ,s.
    → Selection: "Hello", name, "welcome aboard".
  4. Put cursor anywhere inside the hello function body. Press .d.
    → Selection: the whole def hello(name) do ... end. If this doesn't work cleanly in Elixir mode, that's meow-tree-sitter earning its keep. You have it installed; the defun thing uses tree-sitter when available.
  5. Cursor on any line. Press .p.
    → Selection: the whole paragraph (separated by blank lines).
  6. Anywhere. Press .b.
    → Selection: the entire buffer. (One keystroke pair instead of C-x h.)

Apply — a real refactor, no C-SPC

Goal: change the docstring on hello.

  1. Move cursor onto the docstring line (any column inside the string).
  2. ,g — select inside the quotes.
  3. c (meow-change) — deletes selection, drops you in insert state.
  4. Type the new docstring. ESC back to normal.

Compare to your old workflow: position cursor at start of text, C-SPC, move to end of text, C-w, type. You just saved 4–6 keystrokes on a move you do dozens of times a day.

Stretch — combine with expansion from Lesson 0001

Things compose with expansion. Cursor on the parts = line:

  1. .l — select this line as a thing.
  2. 3 — expand to 3 things (lines).
  3. k — kill all three. (Remember: k, not d. See the kill-vs-delete card.)
  4. z to undo.

Same shape as Lesson 0001, structural unit instead of word. The mental model is paying compound interest already.

Win condition

You're done when, without thinking:

  • You can change a string's contents in 3 keystrokes (,gc).
  • You can kill an entire function in 2 (.d) then k.
  • The next time you start to press C-SPC, you pause and ask: "is this a thing?"
