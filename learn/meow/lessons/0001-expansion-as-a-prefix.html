Lesson 0001 · ~7 minutes

Expansion as a prefix

Skill Selection-first thinking · Mission Reflexive expansion · advanced moves

The one idea

In meow, a selection is the argument to your next command. Most "movement" keys don't just move the cursor — they grow, shrink, or reshape the selection that any verb (d, c, k, x, ;) will then act on.

The fastest entry point to that mindset is expansion: the digits 1–9 in normal state don't type digits — they expand your last motion N times.

"meow-line will create regions for every N lines (N is the number of selected lines)."
— meow tutorial

The mechanic

Every meow motion that selects something — w (next word), e (line), W (next symbol), f (find char) — leaves an active selection direction. Then:

  • 3 means "do that selection 3 times". w3 → select 3 words.
  • : reverses the selection direction. w:2 → 2 words backward.
  • Any verb you press next operates on the whole selection. w3d deletes three words; e5; comments five lines.

This is the prefix-argument pattern that vim spells 3dw. Meow flips it: select first, verb last. Once you internalise that, you stop thinking "how many?" before you act, and start seeing the change before you commit to it.

Why this matters for your mission

Every advanced meow feature you want — things, beacon mode, tree-sitter selection — uses the same shape: build a selection, then verb it. Expansion is the smallest place to feel that shape.

Drill it

Setup (30 seconds)

Open a scratch buffer with some real text. Paste this snippet in (any code is fine, but prose works too):

defmodule Counter do
  def inc(n), do: n + 1
  def dec(n), do: n - 1
  def double(n), do: n * 2
  def square(n), do: n * n
end

Put your cursor at the start of defmodule. Make sure you're in normal state (no insert).

Reps — feel the selection grow

  1. w → one word selected. Look at the highlight.
  2. 3 → highlight now covers 3 words. If you don't see expansion hints (the little 1-9 badges over the next words), run M-x meow-cheatsheet once to confirm meow is active. The expansion overlay is on by default.
  3. : → direction flips; selection now goes backward from where you started.
  4. 2 → 2 words backward.
  5. g → cancel the selection (back to a clean cursor).

That's the whole loop: motion → digit → (optional reverse) → verb.

Apply — a real edit, no insert state

Cursor on the def inc line.

  1. e → select this line. (e = meow-line, always leaves a real active region — verbs work.)
  2. 4 → expand to 4 lines (all four def lines).
  3. ; → comment them all out. (That's your meow-comment binding.)
  4. z → undo, so the buffer is clean again.
  5. Now try the word version: cursor on defmodule, then w 3 k → kills 3 words. (Note k, not d.)
  6. z → undo. Then e 4 / → duplicate all four lines (your custom rock--meow-duplicate).

You just did two non-trivial multi-line edits without ever leaving normal state. That's the shape every later lesson will reuse.

Win condition

You're done with this lesson when, without looking at the cheatsheet, you can:

  • Select 5 words forward and kill them. (w 5 k)
  • Select 3 lines backward and comment them. (e : 3 ;)
  • Say out loud: "the digit comes after the motion, the verb comes after the digit."
