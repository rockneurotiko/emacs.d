Meow Mastery · Lesson 0004

Grab, Swap, Sync

The three verbs that turn your secondary selection into a second clipboard — and make swapping two things a single composed action.

The setup: you already have two clipboards

You've been using Emacs's kill-ring for 10+ years. Meow adds one more: the secondary selection. You met it in Lesson 0003 as the engine behind beacon mode. But secondary selection isn't only for multi-cursor work — it's also a persistent, named grab of a piece of text that you can act on anywhere in the buffer.

Three verbs control it. On your layout:

KeyCommandWhat it does
G meow-grab Save current selection as secondary selection. Doesn't change the text.
R meow-swap-grab Swap current region with secondary selection. Also saves cursor position (for meow-pop-grab).
X meow-sync-grab Replace secondary selection with current region's text. Also saves cursor position.

And one bonus verb you may not be using:

KeyCommandWhat it does
; meow-replace Replace current region with the top of the kill-ring. Selection-first, from the normal kill-ring — no secondary selection needed.

Your Emacs anchor: Think of G as "set the other mark." The secondary selection is a named region stored separately from the kill-ring. R is then "exchange these two named regions," and X is "copy-replace the secondary with what I have here."

Three real patterns

Pattern 1 — Swap two things (G → move → select → R)

Scenario: swap two function arguments in an Elixir call.

  1. Place cursor on :key. Press ,w to select the inner word (or m to mark word).
  2. Press G — saves :key as the secondary selection. The highlight stays.
  3. Move cursor to value. Press m to select it.
  4. Press R — swaps the two. value goes where :key was, and vice versa.

Why R works: meow-swap-grab literally exchanges the text of the two regions. Both the secondary selection and the current region get replaced in one atomic operation.

Pattern 2 — Replace something with a saved piece (G → move → select → X)

Scenario: you have a module alias used in multiple places, and you want a different variable name to appear at a secondary location.

  1. Select Schema (the correct one). Press G to grab it.
  2. Navigate to Schemaa (the typo). Select it with m or M.
  3. Press X — replaces Schemaa with Schema. The secondary selection (Schema) also gets updated to point to its new location.

Note the difference from R: X copies the content of the current region into the secondary selection's location. Nothing comes back to where your cursor is.

Pattern 3 — Replace region with kill-ring (x → move → select → ;)

This one doesn't use the secondary selection at all — it uses your existing kill-ring. You probably use C-w + C-y today. The meow version is cleaner:

  1. Select the text you want to copy. Press x (meow-save — copies to kill-ring without deleting).
  2. Move to the target. Select what should be replaced.
  3. Press ; (meow-replace) — replaces the selection with the kill-ring top.

vs vanilla: M-w then navigate then C-w then C-y is 4 operations. x → select → ; is 3, and the "select first" step means you always know exactly what gets replaced before you replace it.

Practice in a real buffer

Open any Elixir file you've been working on and try each pattern once:

  1. Find two arguments you could swap. Use G → R.
  2. Find a repeated identifier where one is a typo or wrong name. Use G → X.
  3. Copy a module name or variable with x, then use ; to stamp it somewhere else.

The goal isn't to do this in production code — just find any pair and try the motion once.

Ask your teacher anything. If a pattern didn't work, if the secondary selection highlight disappeared before you could use it, or if you're unsure what meow-pop-grab does — just ask. That's what I'm here for.
